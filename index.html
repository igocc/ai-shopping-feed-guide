一、 五大 AI 平台直连全景档案

1. Google Gemini 直连（基于 Google Merchant Center）

Gemini 的商品搜索、比价、推荐及 AI Overviews 的底层全部直接读取 Google Shopping Graph。

申请入口 https://merchants.google.com/ （Google Merchant Center Next）
准入条件 1. 独立域名所有权（公网有效 HTTPS，支持标准结账流程）；
2. 完备政策页面（配送政策 Shipping、退换货 Refund、隐私条款 Privacy）；
3. 真实有效的商家联络信息（电话、客服邮箱、物理地址）。
需准备资料 企业注册英文主体、独立域名 DNS 解析权限（TXT 记录验证）、客服热线及邮箱、退换货与退款政策页面 URL。
Feed 格式 Google Ads Feed 原生格式（首选 XML / RSS 2.0，亦支持 TSV 或 GZ 压缩文件）。
更新频次 每日至少 1 次（全量抓取）。高频库存变动可通过 Supplemental Feed 或 Content API 实时更新。
推送直连方式 1. GMC 后台 -> 数据源 -> 添加主数据源 -> 选择 “计划抓取（Scheduled Fetch）”；
2. 填入：https://feed.yourdomain.com/catalog/google_feed.xml，抓取时间设定为每日凌晨；
3. 关键开关：在“成长/管理计划”中必须启用 “在 Google 上免费发布商品（Free Listings）”。

2. Microsoft Copilot 直连（基于 Microsoft Merchant Center）

Copilot 在 Windows/Edge 及 Web 端回答购物咨询时，底层调取的是必应商业索引与微软 Merchant Center。

申请入口 https://ads.microsoft.com/ -> 工具 -> Merchant Center
准入条件 1. 拥有已激活的 Microsoft Advertising 广告账户；
2. 拥有经 Bing Webmaster Tools 或 UET 标签验证的独立域名；
3. 站点支持 SSL 且包含退换货说明。
需准备资料 微软广告账号、企业执照主体、域名所有权证据（Bing 网站管理员账号或 DNS 验证）。
Feed 格式 100% 兼容 Google Ads Feed（直接复用 google_feed.xml，无需转换）。
更新频次 每日 1 次。
推送直连方式 方案 A（推荐）：在 MMC 中点击“从 Google Merchant Center 导入”，设置每日自动同步；
方案 B：新增 Feed -> 传输方法选择“现有 URL 定期抓取”，填入 google_feed.xml 的外链。

3. Meta AI 直连（基于 Meta Commerce Manager）

Meta AI（覆盖 WhatsApp、Instagram、Messenger 等）在用户搜索或触发商品推荐时，直接检索 Meta 商业目录。

申请入口 https://business.facebook.com/commerce （Meta 商业管理平台）
准入条件 1. Meta Business Suite 管理员权限；
2. 完成域名安全验证（Domain Verification）；
3. 符合《Meta 商业合作商家协议》及《商业交易政策》（禁售仿冒侵权品）。
需准备资料 Meta 商务账户、企业英文名称、已认证的独立站域名、客服联络邮箱。
Feed 格式 Meta Ads Feed 原生格式（首选 CSV 或 TSV，亦支持 RSS XML）。
更新频次 每小时 或 每日 1 次（支持按小时设定拉取计划）。
推送直连方式 1. Commerce Manager -> 目标 Catalog -> 数据源 -> 数据 Feed -> “计划 Feed 上传”；
2. 填入：https://feed.yourdomain.com/catalog/meta_feed.csv；
3. 目录用途确保勾选 “用于商业展示与产品推荐”。

4. Perplexity 直连（基于 Perplexity Merchant Program）

Perplexity 已正式推出原生 Shopping 引擎（Buy with Pro 及商品答案卡），优先索引签约商户的结构化商品。

申请入口 https://www.perplexity.ai/hub/merchant-program （官方商家入驻表单）
准入条件 1. 拥有合法独立电商站点（面向美国或全球合规交付）；
2. 落地页具备完备且可被机器直接读取的结构化代码（Schema.org/Product）；
3. 允许 PerplexityBot 爬取（robots.txt 中不可拦截）。
需准备资料 商家英文名、官方主域名、业务邮箱、商品类目与总 SKU 量、GMC 格式商品 Feed URL。
Feed 格式 直接复用 Google Ads Feed 格式（google_feed.xml）。
更新频次 每日抓取 + 页面访问时实时核对。
推送直连方式 1. 在官方入驻入口填写公司与目录信息，并在 Catalog Feed 项中填入中央 Feed 链接；
2. 在落地页（PDP）嵌入标准 JSON-LD 结构化数据供爬虫实时核验最新价格与库存。

5. Claude 直连（基于自建 MCP Server 直连模式）

Anthropic 官方没有广告录入中心，但其核心开源标准 MCP（Model Context Protocol） 是大模型直连私有数据的首选。

申请入口 无需向中心化平台申请审核，自主搭建即刻生效（Anthropic 开源标准）。
准入条件 具备一台独立云服务器或轻量容器（如 Cloudflare Workers / Docker）。
需准备资料 现有的 google_feed.xml 或 meta_feed.csv 文件，Python / Node 环境。
Feed 格式 服务端本地定时读取 Feed 文件，解析为轻量 SQLite 或内存 JSON 索引。
更新频次 Linux Cron 定时任务，每小时或每日从中央 S3/R2 下载最新 Feed 覆盖本地索引。
推送直连方式 1. 部署极简 Python MCP Server（暴露 search_products 和 get_product_detail 两个只读工具）；
2. 在 Claude 客户端或内部智能体配置接入该 MCP 端点，即可让 Claude 对话毫秒级检索最新商品数据。

二、 全平台 Feed 核心字段标准对照表

只要自建导出脚本支持以下标准字段，即可无损分发给上述所有平台：
通用字段含义 Google Gemini / Copilot / Perplexity (GMC XML) Meta AI (Meta CSV) 规则与值约束
商品唯一 ID <g:id> id 变体级唯一且不可变（如 SKU-1001-BLK）
商品标题 <g:title> title 纯文本，含核心变体属性，≤ 150 字符
商品描述 <g:description> description 真实客观，严禁包含 HTML 标签，≤ 5,000 字符
商品落地页 <g:link> link 公开可达的绝对 HTTPS URL，默认选中对应变体
商品主图 <g:image_link> image_link 对应变体的真实图片直链（JPEG/PNG）
价格 <g:price> price 数字 + 币种，如 79.99 USD
促销价 <g:sale_price> sale_price 真实有效促销价，如 59.99 USD（无促销则留空）
库存状态 <g:availability> availability 严格枚举：in_stock, out_of_stock, preorder
品牌 <g:brand> brand 页面展示的真实商标/品牌名
成色 <g:condition> condition 固定枚举：new, refurbished, used
标准条码 <g:gtin> gtin 8/12/13/14 位 UPC/EAN 标准码（有则必填）
母商品分组 <g:item_group_id> item_group_id 多变体商品归属的同一父级 ID

三、 从 0 到 1 落地执行四步走

  1. 第 1 天：生成并托管中央 Feed 文件
    编写服务端定时脚本从数据库每日导出 google_feed.xml 和 meta_feed.csv，推送到 S3/R2 生成公共固定链接。
  2. 第 1-2 天：配置三大主流 AI 商业后台
    - GMC：配置 Scheduled Fetch（每日拉取），勾选“免费发布商品”（覆盖 Gemini）；
    - MMC：关联 GMC 一键同步或配置定时抓取（覆盖 Copilot）；
    - Meta Commerce：配置定时 Feed，设置更新频率（覆盖 Meta AI）。
  3. 第 2-3 天：提交 Perplexity 官方商家入驻
    提交官网 Merchant Form，填写中央 google_feed.xml 链接，并确保落地页 JSON-LD Product Schema 正确输出。
  4. 第 3 天：搭建 Claude MCP 服务（选配）
    部署基于本地 Feed 缓存的轻量 MCP 检索服务，供 Claude 客户端或内部自动化接入。
